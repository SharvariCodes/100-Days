# 100-Days
My 100-day redemption arc. I’ve started, stopped, procrastinated, and bailed before. Not this time. I’m going from Analytics → Data Science, building from Classical ML through Deep Learning, GenAI, RAG and Agentic AI. One day. One concept. One commit. For 100 days, I’m locked in.

# 🚀 100 Days of Data Science

> A 100-day journey to rebuild my Data Science foundations, strengthen my ML intuition, and move toward modern AI, GenAI, and Agentic AI.

This repository documents my **100 Days of Data Science** journey — from classical Machine Learning fundamentals to Deep Learning, NLP, GenAI, RAG, Agentic AI, MLOps, AI Safety, and portfolio projects.

The goal isn't just to complete tutorials.  
It's to **learn → implement → build → document → repeat.**

---

## 🎯 Why I'm Doing This

I've spent a lot of time learning Data Science in pieces — studying concepts, starting projects, and sometimes leaving things unfinished.

This challenge is my attempt to change that.

For the next 100 days, I'm focusing on:

- 🧠 Building strong ML fundamentals
- 💻 Implementing algorithms instead of treating them as black boxes
- 📊 Strengthening practical Data Science skills
- 🤖 Learning modern NLP, GenAI, and LLM concepts
- 🔎 Building RAG and Agentic AI systems
- 🛠️ Developing real projects along the way
- 📝 Documenting what I learn every day
- 🔥 Most importantly — **finishing what I start**
